# D2

D2 is a newer and fancy diagram created by Terrastruct.

The support is weird.

- Supported by `mark`
- Not natively supported on GitHub
- Need extension and local installation editor

Can't say it's the best.

## Inline

```d2
shape: sequence_diagram
Alice -> John: Hello John, how are you?
Alice -> John.ack: John, can you hear me?
John.ack -> Alice: Hi Alice, I can hear you!
John -> Alice: I feel great!
```
