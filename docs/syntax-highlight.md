# Syntax highlight

You got the benefit of syntax highlighting on GitHub and Confluence! _Well,_ the support is always there in Confluence, but selecting it from dropdown is annoying.

```ts
interface User {
  id: string;
  name: string;
  gender?: boolean;
}
```

```kotlin
data class User(
    val id: String,
    val name: String,
    val gender: Boolean? = null
)
```
